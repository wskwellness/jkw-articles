# Journal of Kinesiology and Wellness: HTML articles

This repository holds the HTML (web) versions of articles published in the
*Journal of Kinesiology and Wellness* (JKW), a peer-reviewed, open-access journal of the
Western Society for Kinesiology and Wellness.

**Read the articles:** <https://articles.wskw.org>

**Journal website, PDFs and submissions:** <https://jkw.wskw.org>

Each article is also listed on the journal website with its DOI, citation details and PDF.
To cite an article, please use its DOI.
